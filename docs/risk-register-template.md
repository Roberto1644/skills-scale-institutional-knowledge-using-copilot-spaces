# Risk Register Template

Use this simple table to track project risks.

| ID | Description | Impact (H/M/L) | Likelihood (H/M/L) | Owner | Mitigation | Status | Notes |
|----|-------------|----------------|--------------------|-------|------------|--------|-------|
| R-001 | Example risk description | High | Medium | @owner | Action to reduce impact | Open | Additional context |

Guidance
- Review and update the register at weekly syncs
- Assign an owner for each risk and a concrete mitigation step
- Close risks when they are no longer applicable
